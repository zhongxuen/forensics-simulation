- **Source commit:** `4c62fe9df5c2f3d3fa3ff97f22c4f7f9912f94e5` (2026-09-18, "Read the missions folder in the e2e suite, and measure the map honestly"). Copied with `git archive` from that commit, so nothing uncommitted came along.
- **Copied:** 2026-09-22.
- **Rule:** before changing a vendored file, check whether the change belongs upstream. After changing one, update its row here.

## Decisions made while copying (owner, 2026-09-22)

1. **`src/sim/net/` is kept, unchanged.** The plan said to drop it "unless a test needs them", but the engine core imports it (`core/scenario.ts`, `core/session.ts`, `core/types.ts`, `core/validate.ts`, `sim/types.ts`), and so do `ping` and `ifconfig`. Keeping it leaves the engine byte-identical to the source. `src/sim/tools/target.ts` (used by `ping`) comes with it.
2. **Support files the listed modules import are vendored too**, unchanged (the "pulled in by" section below).
3. **`logview` is kept** for file 07's `logq` to borrow from.
