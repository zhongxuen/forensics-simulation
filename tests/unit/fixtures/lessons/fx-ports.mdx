## The one-sentence version

Every computer has numbered doors called <Term id="port">ports</Term>.

## How it actually works

### Who answers the door

A <Term id="service">service</Term> listens behind a port.

```console title="Try this"
$ logview /var/log/auth.log
```

| Port | Usually       |
| ---- | ------------- |
| `22` | remote logins |
| `80` | websites      |
