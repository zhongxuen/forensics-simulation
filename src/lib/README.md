# src/lib

Cross-cutting helpers: the app's section list (`app-sections.ts`), the "Start here" destination (`next-step.ts`, and `next-step-from-runs.ts` for `nextStepFor`, which reads the saved runs), command palette matching (`command-search.ts`), search over lessons, glossary and commands (`search.ts`: the index's shape and `searchIndex`), terminal colour themes as CSS (`terminal-themes.ts`), progress maths (`progress.ts`), the contrast checker and audit behind `/styleguide` (`contrast.ts`, `contrast-audit.ts`, `css-custom-properties.ts`), the HTTP security headers and Content Security Policy that `next.config.ts` sends (`security-headers.ts`, phase 11), and small utilities like `cx.ts`. `analytics/` is the anonymous usage counts (phase 11, `md-files/metrics.md`): the event types (ids and coarse buckets only, at most two properties), `trackUsage`, `reportFirstTick` and `beforeSendUsage`, which send nothing under Do Not Track, Global Privacy Control, or with the `usageCounts` setting off. `settings/` is the settings module and `case-storage/` holds saved case runs (see their READMEs): the only two things the app keeps between visits, and the only code allowed to touch browser storage (`tests/unit/storage-guard.test.ts`).

Never import here: features, `src/app`, or React components. The simulation engine must not import from here.
